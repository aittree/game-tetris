## 2. 图片素材

### 2.1 清单

| 文件 | 尺寸 | 格式 | 体积 | 用途 | 绘制位置 |
| --- | --- | --- | --- | --- | --- |
| `images/bg_menu.png` | 720×800 | PNG RGB | 829 KB | 主菜单 / 设置 / 排行榜 / 昵称页背景 | 整屏 1:1 `blit` |
| `images/bg_game.png` | 720×800 | PNG RGB | 597 KB | 游戏界面背景 | 整屏 1:1 `blit`，其上叠加棋盘面板 |
| `images/logo.png` | 512×512 | PNG RGBA | 174 KB | 主菜单标题徽标 | 缩放到 240×240，居中绘制 |
| `images/blocks.png` | 512×64 | PNG RGBA | 4.0 KB | 七种方块 + 幽灵的贴图 | 按 64×64 切分后缩放到 30×30 |
| `icon.png` | 256×256 | PNG RGBA | 52 KB | 窗口图标（`display.set_icon`） | 不缩放 |
| `icon.ico` | 多尺寸 | ICO | 85 KB | exe 文件图标（PyInstaller `icon=`） | 不参与运行 |

### 2.2 背景图约定

- 分辨率**必须**是 720×800（与 `config.CANVAS_W/H` 一致），否则会被拉伸或裁切。
- 背景需为**低对比、深色**：棋盘面板本身是半透明深色层，背景太亮会让方块颜色对比度不足。
- 左侧中部留出偏暗区域供棋盘使用；右侧无需预留，因为右侧面板同样是半透明层。
- `bg_game.png` 由原图裁掉 8.5% 边框后裁切而来（原图带圆角装饰框）；`bg_menu.png` 裁 4.5%。程序内不再做二次裁剪。

### 2.3 贴图带索引（`blocks.png`）

固定 8 格横向排列，每格 64×64，渲染时统一缩放到 30×30。**顺序不可变**，`Renderer` 按索引取图：

| 索引 | 方块 | 颜色 | RGB |
| --- | --- | --- | --- |
| 0 | I | 青 | `#00E5FF` `(0,229,255)` |
| 1 | J | 蓝 | `#3D5AFE` `(61,90,254)` |
| 2 | L | 橙 | `#FF9F1C` `(255,159,28)` |
| 3 | O | 黄 | `#FFD60A` `(255,214,10)` |
| 4 | S | 绿 | `#2EE6A8` `(46,230,168)` |
| 5 | T | 紫 | `#B14EFF` `(177,78,255)` |
| 6 | Z | 红 | `#FF4D6D` `(255,77,109)` |
| 7 | 幽灵 | 灰蓝 | `#7882A0` `(120,130,160)`，绘制时整体 alpha≈90 |

每格包含：外发光、圆角主体、上部白色高光、2 px 内描边。这样即使贴图叠在深色棋盘上，边缘也有清晰的轮廓。

### 2.4 图标

- `icon.png` 与 `icon.ico` 由同一张 Logo 生成，保证窗口图标与 exe 图标视觉一致。
- ico 必须含 16/24/32/48/64/128/256 七种尺寸；缺尺寸会导致任务栏、属性页显示模糊或空白。
- 256×256 的 ico 由 PNG 压缩存储（Windows Vista+ 支持），文件仅 85 KB，不必担心体积。

## 3. 音频素材

### 3.1 技术规格

| 项 | 值 | 说明 |
| --- | --- | --- |
| 采样率 | 22050 Hz | 芯片音乐足够，体积减半 |
| 位深 | 16 bit | 兼容性最好 |
| 声道 | 单声道 | 音效不需要立体声定位 |
| 容器 | WAV（PCM） | 无需解码库，`pygame.mixer` 直接加载 |
| BGM | 31.00 s，可循环 | `pygame.mixer.music.play(-1)` |
| 初始音量 | 音乐 70 / 音效 80 | 见 `storage.Settings` 默认值 |

### 3.2 音效清单与触发

| 文件 | 时长 | 触发时机 | 设计要点 |
| --- | --- | --- | --- |
| `sfx_move.wav` | 0.06 s | 左右移动成功 | 极短噪声 + 950 Hz 短音，不刺耳，连发时不吵 |
| `sfx_rotate.wav` | 0.10 s | 旋转成功（含踢墙） | 720→1080 Hz 双音，上行感表示「转动」 |
| `sfx_lock.wav` | 0.14 s | 方块锁定 | 150 Hz 低音 + 低通噪声，落地「闷响」 |
| `sfx_clear.wav` | 0.34 s | 消 1～3 行 | 4 音符上行琶音，消除越多越亮 |
| `sfx_tetris.wav` | 0.60 s | 一次消 4 行 | 5 音符琶音 + 1.76 kHz 闪烁层，明显区别于普通消行 |
| `sfx_levelup.wav` | 0.55 s | 等级提升 | 5 音符上行，配合顶部等级数字变化 |
| `sfx_gameover.wav` | 1.60 s | 顶出 / 锁出 | 下行四音 + 低频底噪，情绪收束 |
| `sfx_menu.wav` | 0.05 s | 菜单悬停 / 点击 | 1.2 kHz 短促点击，音量仅 0.25 |
| `sfx_pause.wav` | 0.30 s | 暂停 / 继续 | 680→460 Hz 双音，下行为暂停、上行为继续（同一文件倒放感不强，统一播放即可） |

**触发约束**（避免音画不同步或重复播放）：

- 音效由 `main.py` 消费 `GameEvent` 后播放，模型层不直接调 `Audio`。
- 锁定与消行在同一帧发生时，先播 `lock` 再播消行音，两个通道并行，不做队列等待。
- 硬降不单独设音效，用 `lock` 代替（落地即锁）。
- 暂停时 BGM `pause()`，音效自然结束；继续时 `unpause()` 从原位置续播。

### 3.3 BGM

`bgm_main.wav` 为**原创芯片音乐**：8 小节一循环、重复 5 次共 31 秒，160 BPM，和声进行 Am–F–C–G，旋律取 A 小调五声音阶的分解音型，配三角波低音与噪声鼓组。首尾各 0.3 秒淡入淡出，循环时不会出现「咔哒」爆音。

> 未使用《Korobeiniki》（常见「俄罗斯方块主题曲」）录音或改编版本，避免版权与商标关联问题；旋律与音色全部由 `tools/gen_audio.py` 程序合成。

### 3.4 音量与静音

- 音乐、音效音量独立存于存档，范围 0～100。
- 音量 0 时 BGM `pause()`，避免空转；音效音量 0 时 `play()` 直接返回。
- 无声卡环境下 `Audio.available=False`，所有调用安全跳过，不影响游戏逻辑与帧率。

## 4. 生成脚本

素材**全部可复现**，不依赖手工操作：

| 脚本 | 输入 | 输出 | 依赖 |
| --- | --- | --- | --- |
| `tools/gen_sprites.py` | `_src/bg_game_src.png`、`_src/bg_menu_src.png`、`_src/logo_src.png` | 2 张背景、`logo.png`、`blocks.png`、`icon.png`、`icon.ico` | Pillow ≥ 10 |
| `tools/gen_audio.py` | 无（纯程序合成） | 10 个 WAV | numpy ≥ 1.26 |

运行：

```powershell
python -m pip install pillow numpy
python tools\gen_sprites.py
python tools\gen_audio.py
```

参数位置：

- 配色：`gen_sprites.py` 顶部 `BLOCK_COLORS`（与 `config.PIECE_RGB` 一一对应，改色需两处同步）。
- 格子尺寸：`CELL = 64`（贴图 64 px → 渲染 30 px，2 倍余量让方块在高分屏下依然清晰）。
- 背景裁边：`prepare_background(..., crop=0.085/0.045, darken=0.9/0.95)`。
- 音乐：`gen_audio.py` 的 `bgm_main()` 中 `bpm`、`prog`（和声）、`melody`（旋律）可直接改写。

### 4.1 源图管理

`_src/` 存放 AI 生成的原图（约 8 MB），**不进 Git、不进打包**：

- `bg_game_src.png`、`bg_menu_src.png` 为 1457×1618 的原始构图，带装饰边框，需脚本裁切。
- `logo_src.png` 为白底徽标，脚本用洪水填充抠底并清理白边；若重新生成 Logo，务必让背景为纯白、主体不与画面边缘相接，否则抠图会残留光晕。

### 4.2 修改素材的正确流程

1. 改脚本参数或替换 `_src/` 原图；
2. 重新执行脚本；
3. 目视检查背景裁切、Logo 透明度、贴图顺序；
4. 试听 10 个音频，重点听 BGM 循环接缝与消行音是否刺耳；
5. 提交新的二进制产物，**不要**手工 P 图后让产物与脚本不一致。

## 5. 替换与换皮指南

| 想改什么 | 要动的文件 | 必须保持的约束 |
| --- | --- | --- |
| 方块配色 | `config.PIECE_RGB` + `tools/gen_sprites.py` 的 `BLOCK_COLORS` | 两处 RGB 完全一致；重跑贴图脚本 |
| 方块质感（金属/玻璃/像素风） | `gen_sprites.py` 的 `build_blocks()` | 仍为 8 格 × 64 px，透明底，主体不超出格内 4 px 边距 |
| 背景风格 | 替换 `_src/bg_*_src.png` 后重跑 | 输出保持 720×800、深色低对比 |
| 标题 Logo | 替换 `_src/logo_src.png`（白底、居中、不与边缘相接） | 输出 512×512 透明底，主体留 5% 安全边距 |
| 图标 | 无需单独改，随 Logo 一起生成 | ico 必须含 16～256 七种尺寸 |
| BGM | `gen_audio.py` 的 `bgm_main()` | 时长 20～40 s，首尾淡入淡出，单声道 22050 Hz |
| 音效 | 对应 `sfx_*()` 函数 | 时长控制在 0.05～1.6 s；音量归一化后再进游戏 |
| 中文字体 | 替换 `assets/fonts/msyh.ttc` | 必须是 TrueType/OpenType 集合（`.ttc`/`.ttf`），且包含界面全部汉字 |

若替换字体，需回归 07 文档中的全部文案与排行榜昵称输入，确认无缺字。

```powershell

}
```
