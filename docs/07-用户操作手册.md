## 1. 这是什么

一个 Windows 桌面版的俄罗斯方块（Tetris）：方块从顶部落下，把整行填满就能消除，消得越多、速度越快。

- 单文件绿色版，双击即玩，**不需要安装**、不需要联网、不需要 Python。
- 键盘操作，自动保存最高分、设置与排行榜。
- 自带背景音乐与音效，可分别调节音量或静音。

---

## 2. 开始游戏

### 2.1 用 exe（推荐）

1. 双击 `俄罗斯方块.exe`（首次启动约 1～3 秒，请稍候）。
2. 窗口打开后进入主菜单，点「开始游戏」即可，无需额外设置。

> 若双击没有反应：先确认是否被 Windows 拦截（见 6.1）；onedir 版本请勿单独拷贝 exe，必须保留整个文件夹。

### 2.2 用源码（开发者）

```powershell
conda activate game
python -m pip install pygame
python main.py
```

需要 conda `game` 环境（Python 3.12）与 pygame 2.5+，详见《04-开发规范与环境搭建》。

## 3. 界面说明

```
┌──────────────────────────────────────────────────────────┐
│  俄罗斯方块（Tetris）          分数 12800   等级 3       │ ← 顶部信息
│                              行数 27                     │
│  ┌──────────────────────┐   ┌──────────────────────┐     │
│  │                      │   │  HOLD（暂存）         │     │
│  │   游戏区 10×20        │   ├──────────────────────┤     │
│  │                      │   │  NEXT（接下来 5 个）  │     │
│  │                      │   ├──────────────────────┤     │
│  │                      │   │  操作提示             │     │
│  └──────────────────────┘   └──────────────────────┘     │
│  ← → 移动   ↑ 旋转   空格 硬降   C 暂存   P 暂停          │
└──────────────────────────────────────────────────────────┘
```

- **分数**：本局累计得分，消行、软降、硬降都会加分。
- **等级**：每消 10 行升 1 级，等级越高下落越快，消行得分倍率也越高。
- **行数**：本局累计消除的行数。
- **HOLD**：暂存槽，按 C 把当前方块存起来待用。
- **NEXT**：接下来会出现的 5 个方块，可提前规划。

## 4. 操作方法

| 按键 | 作用 |
| --- | --- |
| ← / A | 向左移动 |
| → / D | 向右移动 |
| ↓ / S | 软降（加速下落，每格 +1 分） |
| ↑ / X | 顺时针旋转 |
| Z | 逆时针旋转 |
| 空格 | 硬降（直接落到底，每格 +2 分） |
| C | 暂存 / 交换当前方块（每块只能用一次） |
| P 或 ESC | 暂停 / 继续 |
| F11 | 窗口 / 全屏切换 |
| R | 游戏结束后再来一局 |
| Enter | 菜单确认、昵称保存 |
| ESC | 关闭弹窗、昵称页跳过 |

按住左右键会先停顿约 0.17 秒，然后连续移动，这是有意设计，便于微调落点。

鼠标可用于菜单、设置、排行榜与按钮点击；游戏进行中推荐全程键盘。

### 4.1 暂停与重开

按 P 或 ESC 暂停，画面出现遮罩并停止计时。暂停界面提供「继续」「重新开始」「返回主菜单」。重开会二次确认，确认后分数清零。

### 4.2 设置

主菜单 →「设置」：

- **音乐音量 / 音效音量**：0～100，步进 10，调完立即生效并自动保存。
- **幽灵方块**：开 / 关，显示或隐藏落点预览。
- **显示模式**：窗口 / 全屏，等同于 F11。

### 4.3 排行榜与昵称

- 本机保存历史最高分 **前 10 名**，显示名次、昵称、分数、等级、行数与登记日期，同分先到先得。
- 一局结束或中途退出时，若本局分数能进前 10，可点「登记成绩」输入昵称。
- 昵称支持中英文与数字，最长 12 个字符，留空按「匿名」；Enter 保存，ESC 跳过。
- 输入框内有闪烁光标，中文输入法的候选框会出现在输入框附近。
- 0 分不会进榜。

## 5. 规则与计分

1. 七种方块（I、J、L、O、S、T、Z）从顶部下落，随机按「每 7 个含全部 7 种」的规则发放，不会长时间不出长条。
2. 用 ← → 调整位置，↑ / X / Z 旋转，贴到底部约 0.5 秒后自动固定。
3. 某一行 10 格填满即消除，上方所有行整体下移。
4. 一次消多行分数更高：

| 消除行数 | 得分 |
| --- | --- |
| 1 行 | 100 × 等级 |
| 2 行 | 300 × 等级 |
| 3 行 | 500 × 等级 |
| 4 行 | 800 × 等级 |

5. 软降每格 +1 分，硬降每格 +2 分。
6. 每累计消 10 行升 1 级；等级越高下落越快，得分倍率越高。
7. 方块堆到顶部、新方块放不下时，游戏结束。

### 5.1 玩法思路

- **留一列空位**：把右侧（或左侧）留出一列，专门等长条 I 块，一次消 4 行。
- **保持地面平整**：宁可不消行，也不要挖出深坑；坑越深越难补救。
- **大块贴边**：把 S/Z 这类凹凸块尽量贴着墙放，中间留给平整的方块。
- **看 NEXT 提前规划**：知道下一个是什么，再决定这一块放哪。
- **善用 HOLD**：遇到不合适的方块先存起来，等场地合适再用；每个方块落地前只能暂存一次。

## 6. 常见问题

### 6.1 双击后提示「已保护你的电脑」/ 被浏览器或杀软拦截

这是无数字签名程序的 SmartScreen 提示，不代表文件有毒：

- 浏览器下载被拦：下载记录中右键 →「保留」。
- SmartScreen：点「更多信息」→「仍要运行」。
- 企业杀软：把 exe 加入信任目录，或改用文件夹版（onedir）。

### 6.2 启动有几秒延迟

onefile 版本每次启动都要先解压自身，属正常现象。介意可让发布方提供 onedir 文件夹版。

### 6.3 没有声音

- 先检查设置里的「音乐音量」「音效音量」是否为 0；
- 确认系统音量与输出设备正常；
- 若程序在无声卡环境（部分虚拟机、远程桌面）运行，会自动静默运行，游戏本身不受影响。

### 6.4 文字变成方块或问号

字体资源缺失或损坏，请使用完整发布包（onedir 版本勿单独拷 exe）；程序会尝试系统字体兜底，但完整包才能保证显示。

### 6.5 最高分突然归零

最高分保存在 `%APPDATA%\TetrisDesktop\save.json`。清理系统文件、换 Windows 账户或手动删除该文件都会重置；这是本机存档，不随 exe 走。

### 6.6 按键没反应

确认窗口处于激活状态（先点一下窗口）；若在暂停或结束界面，需要先点「继续」或「再来一局」。

### 6.7 方块转不动

贴着墙或紧挨地形旋转时，程序会按标准规则尝试小幅位移（踢墙）；如果所有位置都放不下，本次旋转会被取消，这是正常行为。

## 7. 卸载与清理

本程序不写注册表、不装服务：

1. 删除 `俄罗斯方块.exe`（或整个程序文件夹）。
2. 如需清空纪录与设置，删除 `%APPDATA%\TetrisDesktop\` 文件夹。
